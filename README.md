# SQL Sales Analysis

## About the Project

This project focuses on analyzing e-commerce sales data using SQL to understand sales performance across products, categories, cities, and different months.

The project uses SQL queries to organize the data, calculate important sales metrics, and identify useful patterns from the sales records.

## Tools & Skills

- SQL
- SQLite
- Data Analysis
- Aggregate Functions
- GROUP BY
- ORDER BY
- Filtering & Sorting
- Joins
- Subqueries

## Key Analysis

- Total sales and revenue
- Product-wise sales performance
- Category-wise revenue
- Monthly sales trends
- City-wise sales
- Product sales ranking
- Quantity and revenue analysis

## Project Highlights

The analysis includes sales data for different products and categories and uses SQL queries to compare their performance.

Some of the analysis areas include:

- Identifying products with higher sales
- Comparing revenue across categories
- Analyzing monthly sales performance
- Comparing sales across different cities

## Objective

The main objective of this project was to practice SQL for real-world data analysis and understand how SQL queries can be used to extract meaningful information from sales data.
